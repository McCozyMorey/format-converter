# SubConverter

> 格式转换工具箱｜Format Converter Toolbox

**🔗 https://subconverter-kohl-ten.vercel.app/**

---

## 中文

纯浏览器端格式转换工具站，无需服务器，文件不上传。

### 工具

| 工具 | 说明 |
|------|------|
| 📝 **字幕转换** | VTT · SRT · ASS · SSA · LRC · SBV 任意互转，批量 + ZIP 打包 |
| 🖼 **图片转换** | PNG / JPEG / WebP 互转，支持质量调节与缩放（Canvas 客户端处理） |
| ⏱ **时间戳** | Unix 秒/毫秒 ↔ 日期时间，实时当前时间 |
| 🔢 **进制转换** | 十进制 / 十六进制 / 八进制 / 二进制互转（任意精度） |
| 🎨 **颜色转换** | HEX / RGB / HSL / HSV 互转，内置取色器 |
| 📏 **单位换算** | 长度 · 重量 · 温度 · 数据大小（SI 与二进制）· 时间 |

### 使用

1. 顶部 Tab 选择工具
2. 拖拽或选择文件（字幕/图片）或输入数值
3. 查看结果，复制或下载

界面根据浏览器语言自动切换中英文，右上角可手动切换。

## English

A fully client-side format converter toolbox — no server, files never leave your browser.

### Tools

| Tool | Description |
|------|-------------|
| 📝 **Subtitle** | Convert between VTT · SRT · ASS · SSA · LRC · SBV, batch + ZIP download |
| 🖼 **Image** | PNG / JPEG / WebP conversion with quality & resize (Canvas client-side) |
| ⏱ **Timestamp** | Unix seconds/ms ↔ datetime, live current time |
| 🔢 **Base** | Decimal / Hex / Octal / Binary conversion (arbitrary precision) |
| 🎨 **Color** | HEX / RGB / HSL / HSV conversion with color picker |
| 📏 **Unit** | Length · Weight · Temperature · Data (SI & binary) · Time |

### Usage

1. Pick a tool from the top tabs
2. Drag & drop or select files (subtitle/image), or type values
3. Copy or download the result

The UI auto-detects your browser language and can be toggled at top-right.
